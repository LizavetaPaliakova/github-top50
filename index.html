GitHub на пальцах за 30 секунд

    
Это не секта программистов, а огромный бесплатный склад программ. Чтобы там не потеряться, хватит трёх слов.

    

      
📁
Репозиторий
Папка проекта с открытым кодом. Ссылка вида github.com/автор/проект. Главное — читать файл README внизу страницы: это инструкция.

      
★
Звёзды
Лайки от разработчиков. Тысячи звёзд + свежие обновления = проекту можно доверять. 12 звёзд и последний коммит в 2019-м = беги.

      
⬇
Releases
Справа на странице проекта. Там лежат готовые установщики: скачал .exe или .dmg — поставил. Никакого кода.

    

    
Три способа установки

    
У каждой карточки есть метка. Смотри на неё и выбирай по силам.

    

      
Скачал и запустил
Как обычная программа
Установщик с сайта или из Releases. Справится даже бабушка, если ей пообещать внуков.

      
Одна команда
Через терминал
Windows: Пуск → «Терминал». Mac: Spotlight → «Терминал». Вставляешь команду из карточки, жмёшь Enter. Иногда сначала нужен Python (python.org) или Node.js (nodejs.org).

      
Через Docker
Свой сервер в коробке
Ставишь Docker Desktop (docker.com) — и запускаешь целые сервисы командой. Для CRM, аналитики и рассылок, которые живут у тебя, а не у дяди.
