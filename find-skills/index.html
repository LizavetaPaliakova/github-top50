Find Skills: ставим скилл одним промптом

Один скилл, который сам находит нужные скиллы под твою задачу. Одна ссылка и один промпт – Claude Code или Codex поставят его сами, без скачивания и команд.

Обещал в ролике: «но я уже подготовил готовый файл, просто скачай его, загрузив свои скиллы и готово. Напиши в комментариях слово «один» и я пришлю его тебе.»

Что это за скилл

Один скилл, который ищет остальные скиллы за тебя.

Как консультант в большом строительном магазине: не бродишь по рядам сам, а говоришь «мне покрасить стену» – и тебя ведут к нужной полке.

Find Skills – скилл от Vercel. Ты пишешь Claude обычной фразой, что хочешь сделать: смонтировать ролик, сделать сайт, презентацию. Claude смотрит каталог скиллов skills.sh, выбирает подходящие, проверяет, сколько у них установок и кто автор, и показывает тебе варианты со ссылками.

Скачивать ничего не нужно. Ты даёшь Claude Code или Codex ссылку на скилл – и он сам кладёт его куда надо. Ниже четыре шага: открыть, установить, проверить, пользоваться.

Шаг 1. Открой Claude Code или Codex

Подойдёт любой из двух – выбери тот, которым уже пользуешься.

Как позвать мастера: сначала открываешь ему дверь, дальше он всё делает сам.

Claude Code

  1. Скачай приложение Claude для компьютера: claude.com/download. Установи и войди в аккаунт.
  2. Нажми вкладку Code вверху окна, затем + New слева – начнётся новая сессия.
  3. Выбери под полем ввода любую свою папку – в ней Claude будет работать.

Codex

  1. Скачай приложение ChatGPT для компьютера, в нём есть Codex: learn.chatgpt.com/docs/app → кнопка «Download». Войди через свой аккаунт ChatGPT.
  2. Открой Codex и начни новую задачу в любой своей папке.

Что должно получиться

  • Перед тобой пустое поле ввода новой сессии.

Вкладка Code работает на платных тарифах Claude (Pro и выше), Codex – на тарифах ChatGPT, включая бесплатный. В обычном чате claude.ai скилл по ссылке не ставится – там скиллы загружаются только файлом, поэтому работаем в Code или Codex.

Шаг 2. Установи скилл одним промптом

Ссылка на готовый файл скилла уже внутри промпта – Claude сам заберёт его с GitHub.

Как скинуть мастеру ссылку на товар: он сам заказывает, приносит и ставит на место.

  1. Нажми «Скопировать» у промпта ниже.
  2. Вставь его в поле ввода и нажми Enter.
  3. Claude будет спрашивать разрешение на действия – прочитай, что он хочет сделать, и разреши.
Установи мне скилл Find Skills по ссылке https://github.com/vercel-labs/skills/tree/main/skills/find-skills
Возьми папку find-skills целиком, без изменений, и положи туда, откуда ты сам читаешь скиллы для всех моих проектов. Ничего другого не устанавливай.
Сделай всё сам, мне объясняй простыми словами, что делаешь. В конце одной строкой скажи, где теперь лежит скилл и что нужно, чтобы он заработал.

Что должно получиться

  • Claude пишет, что скилл find-skills установлен, и называет папку, куда его положил.
  • Если он просит перезапустить сессию – нажми + New и начни новую.

Шаг 3. Проверь, что скилл работает

Одна тестовая просьба – и видно, подхватил Claude скилл или нет.

Как после установки новой лампочки щёлкнуть выключателем.

  1. Начни новую сессию: + New.
  2. Вставь промпт ниже кнопкой «Скопировать» и нажми Enter.
Используй скилл find-skills. Найди мне скиллы для монтажа коротких вертикальных роликов. Покажи 3 лучших варианта: что умеет каждый, сколько у него установок, кто автор и ссылку. Объясняй простыми словами.

Что должно получиться

  • Claude отвечает списком скиллов: название, что делает, число установок, автор и ссылка на skills.sh.
  • Если в ответе есть такие ссылки и цифры установок – скилл сработал.
Claude ответил «из головы» и не нашёл скилл

Начни новую сессию и вставь промпт из шага 2 ещё раз, добавив в конце: «Проверь, что скилл виден в новой сессии, и если нет – исправь».

Шаг 4. Пять просьб, с которых начать

Пиши задачу своими словами – найти скилл Claude догадается сам.

Как говорить с консультантом: не название товара, а что хочешь сделать.

Копируй любой промпт, в квадратных скобках меняй на своё.

Сайт

Найди скилл, который поможет сделать красивый одностраничный сайт для [мой бизнес], чтобы он не выглядел как все сайты, сделанные нейросетью.

Презентации

Есть ли скилл для презентаций? Мне нужно сделать презентацию на [тема] на 10 слайдов. Найди подходящий и объясни, как им пользоваться.

Таблицы и документы

Найди скилл для работы с Excel-таблицами: мне нужно разобрать [что за данные] и построить понятный отчёт.

Маркетинг

Найди скиллы для маркетинга небольшого бизнеса: тексты для соцсетей, рекламу и рассылки. Покажи 3 самых популярных и чем они отличаются.

Дизайн

Как мне сделать [логотип / обложку / баннер] для [проект]? Сначала проверь, есть ли для этого готовый скилл.

Что должно получиться

  • На каждую просьбу – несколько скиллов с объяснением и ссылками.
  • Понравился скилл – просто напиши: «Поставь мне [название скилла], который ты нашёл». Claude установит его так же, как Find Skills в шаге 2.

Совет: не ставь всё подряд. Найди один скилл под задачу этой недели и доведи её до результата.
